# dataset-doctor · 训练数据质检工具

上传一份带 `text`、`label` 两列的 CSV，自动找出训练数据里的重复样本、空文本、超短文本、标签冲突和类别不平衡，给出质量评分，并导出清洗后的数据。

数据质量决定模型准确率的上限。重复样本让模型过拟合，标签错标让它学错规律，类别严重不平衡让它只会偏向多数类。这些问题在训练前用肉眼查一遍要半天，这个工具几秒钟就能扫完。

## 功能

- 五类质量问题自动检测，每类给出条数和示例行号
- 百分制质量评分，四档分级（良好 / 中等 / 较差 / 严重）
- 标签分布可视化，少数类高亮提示
- 一键下载清洗后的 CSV，可直接用于训练
- 兼容 UTF-8 和 GBK 编码，自动尝试解码

## 快速开始

```bash
pip install -r requirements.txt
python app.py
```

浏览器打开 `http://127.0.0.1:5001`，上传 CSV 即可。没有数据可以先下载页面上的示例脏数据（541 条，含五类典型问题）。

命令行方式：

```python
import pandas as pd
from inspector import inspect, clean

df = pd.read_csv("data/sample_dirty.csv", encoding="utf-8-sig")
report = inspect(df)
print(report["score"], report["level"])

cleaned, _ = clean(df)
cleaned.to_csv("cleaned.csv", index=False, encoding="utf-8-sig")
```

## 检测项

| 检查项 | 判定规则 | 为什么要查 |
|---|---|---|
| 文本为空 | 去空白后长度为 0 | 空样本对训练没有任何贡献 |
| 文本过短 | 去空白后长度小于 3 | 一两个字的样本没有信息量，容易成为噪声 |
| 完全重复 | 文本完全相同，保留首次出现 | 重复样本会放大权重，导致模型过拟合 |
| 近似重复 | 字符相似度 ≥ 0.92，且长度差不超过 15% | 标点或空格级别的差异没有实质意义 |
| 标签冲突 | 同一文本对应多个标签，保留票数最多的 | 模型无法从同一输入学到两个相反的答案 |
| 标签非法 | 标签为空，或超过 20 个字符 | 标签格式错误会直接导致训练脚本报错 |
| 类别不平衡 | 最小类别占比低于 10% | 模型会偏向多数类，少数类几乎学不到 |

## 评分规则

```
得分 = 100 - 问题行占比 × 300 - (类别不平衡 ? 10 : 0)
```

用占比而不是绝对条数，是为了让不同规模的数据集分数可比：500 条里 50 条问题和 5 万条里 5000 条问题，严重程度是一样的。

- 85 分以上：良好
- 70 到 84：中等
- 50 到 69：较差
- 50 以下：严重

## 已知限制

- 近似重复用 `SequenceMatcher` 两两比对，复杂度 O(n²)，靠长度剪枝优化过。万条以内够用，再大应该换 SimHash 或 MinHash。
- 只接受 CSV，且必须包含 `text`、`label` 两列。JSON、Excel 和自定义列名需要改 `_read_upload`。
- 评分是启发式规则，用于快速筛查，不是学术意义上的数据质量度量。
- 清洗只删除问题行，不处理类别不平衡。补采样或调整损失权重需要在训练侧解决。

## 技术说明

- 近似重复：先按文本长度排序，长度差超过 15% 直接跳过，剩下的用 `difflib.SequenceMatcher` 算相似度。剪枝后实际比较次数远小于 n²。
- 标签冲突：按文本分组后对标签投票，保留票数最多的，其余行判为冲突。这样不会把整组样本删掉，只删除少数派。
- 评分：按问题行占比扣分，避免大数集和小数集分数不可比。
- 文件解析：依次尝试 `utf-8-sig`、`gbk`、`utf-8` 三种编码，任一成功即返回。
